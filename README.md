## ✨ المميزات

- **تتبّع اليد في الوقت الفعلي (Real-time Hand Tracking)** باستخدام مكتبة `@mediapipe/hands` مباشرة من المتصفح.
- **رسم بإيماءات اليد (Gesture Control)** بدون أي لمس للماوس أو لوحة المفاتيح:
  - ☝️ **إصبع السبابة ممدود** → رسم.
  - ✋ **الكف مفتوح بالكامل** → مسح الشاشة بالكامل.
  - ✊ **قبضة اليد** → إيقاف الرسم مؤقتًا.
- **تأثير نيون متوهج (Neon Glow Effect)** على كل خط بترسمه.
- **تخصيص كامل** للون الرسم وسمك الخط مباشرة من لوحة التحكم.
- **معاينة مباشرة للكاميرا** (Webcam Preview) داخل الواجهة لمتابعة يدك أثناء الرسم.
- تصميم **Canvas متجاوب** يتمدد تلقائيًا مع حجم الشاشة.
- يعمل بالكامل داخل المتصفح — **لا حاجة لتثبيت أي برنامج**.

## 🖥️ طريقة التشغيل

المشروع عبارة عن ملف `index.html` واحد مستقل، وكل المكتبات يتم تحميلها تلقائيًا من CDN.

```bash
git clone https://github.com/MRxAlc0h0lic/air-draw.git
cd air-draw
```

بعد كده افتح `index.html` في متصفح حديث (يفضّل **Chrome**) مع السماح بصلاحية الوصول للكاميرا.

> ⚠️ **ملاحظات مهمة:**
> - لازم يكون عندك اتصال بالإنترنت (المكتبات بتتحمّل من CDN وقت التشغيل).
> - بعض المتصفحات بترفض الوصول للكاميرا لو الملف اتفتح مباشرة بـ `file://`. لو حصلت مشكلة، شغّل المشروع عن طريق سيرفر محلي بسيط:
> ```bash
> npx live-server
> ```

## 🎮 طريقة الاستخدام

1. افتح الصفحة وسيبها تاخد صلاحية الكاميرا.
2. استنى لحد ما تتغير حالة `Status` لـ **Waiting...** (يعني فاهم إيدك).
3. اختار اللون والحجم من لوحة التحكم في أعلى الشاشة.
4. مد إصبع السبابة وابدأ ترسم في الهواء.
5. افتح كفك بالكامل عشان تمسح الرسمة، أو اقفل إيدك (قبضة) عشان توقف الرسم مؤقتًا.

## 🛠️ التقنيات المستخدمة

| التقنية | الاستخدام |
|---|---|
| HTML5 / CSS3 | هيكل وتصميم الواجهة |
| JavaScript (Vanilla) | منطق الرسم والتحكم في الحالة |
| Canvas API | رسم الخطوط وتأثير التوهج (Glow) |
| [MediaPipe Hands](https://developers.google.com/mediapipe) | تتبّع نقاط اليد (Landmarks) وتحليل الإيماءات |
| MediaPipe Camera Utils | إدارة تدفّق الكاميرا وإرسال الفريمات للنموذج |
